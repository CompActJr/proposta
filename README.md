# Propostas comerciais

> elaborações de propostas comerciais para sites e e sistemas webs por meio deste repositorio com o github pages

## Regras

1. para cada proposta criar uma pasta nova e um index.html para servir de caminho principal e ser buscavel pela web EX:  atu/index.html
2. Liberado uso de ferramentas generativas para elaboração destas propostas em land pages obedencdo os criterios da regra 3
3. apenas html css e js, qualquer uso de frameworks e de bibliotecas istalaveis será bloqueada neste repositorio
4. não subir arquivos sensiveis e o mesmo vale para dados e variaveis de ambiente neste repositorio
